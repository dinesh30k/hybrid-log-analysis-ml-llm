🎯 NEW API ENDPOINTS
────────────────────────────────────────────────────────────────────────────────

✅ GET /ollama/status
   Returns: Ollama availability, URL, model, status

✅ POST /ollama/analyze
   Input: {"log": "...", "detailed": true}
   Returns: Severity, reasoning, recommendations

✅ POST /ollama/compare
   Input: {"log": "..."}
   Returns: ML prediction + Ollama analysis (side-by-side)

✅ POST /ollama/batch-analyze
   Input: ["log1", "log2", "log3"]

   Returns: Detailed explanation for stored log

🚀 QUICK START
────────────────────────────────────────────────────────────────────────────────

1. Install Ollama
   Download: https://ollama.ai

2. Pull a model
   $ ollama pull llama2
   (or: mistral, neural-chat, openchat)

3. Start Ollama service
   $ ollama serve

4. Setup project (new terminal)
   $ cd ml-api
   $ bash setup.sh  # or setup.bat on Windows

5. Install dependencies
   $ pip install -r requirements.txt

6. Start API (new terminal)
   $ uvicorn app:app --reload

7. Verify
   $ python test_ollama.py

8. Access
   API Docs: http://localhost:8000/docs
   Status:   http://localhost:8000/ollama/status

🎯 USAGE EXAMPLES
────────────────────────────────────────────────────────────────────────────────

Python:
────────
import requests

# Hybrid prediction
response = requests.post('http://localhost:8000/predict', json={
    'log': 'SSL certificate failure',
    'use_ollama': False
})
print(response.json())

# Detailed Ollama analysis
response = requests.post('http://localhost:8000/ollama/analyze', json={
    'log': 'Disk space critical',
    'detailed': True
})
print(response.json())

# Compare predictions
response = requests.post('http://localhost:8000/ollama/compare', json={
    'log': 'Error message'
})
print(response.json())


cURL:
──────
# Check status
curl http://localhost:8000/ollama/status

# Predict
curl -X POST "http://localhost:8000/predict" \
  -H "Content-Type: application/json" \
  -d '{"log": "error"}'

# Analyze
curl -X POST "http://localhost:8000/ollama/analyze" \
  -H "Content-Type: application/json" \
  -d '{"log": "error", "detailed": true}'

# Compare
curl -X POST "http://localhost:8000/ollama/compare" \
  -H "Content-Type: application/json" \
  -d '{"log": "error"}'
